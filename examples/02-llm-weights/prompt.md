# Prompt

User request (verbatim):

> show a diagram animation of a modern llm weight and neuron setup

## Narration assumption (Step 0)

The skill asks the user "spoken narration (Kokoro) or a silent video?" before planning. In this
test run the user could not be reached, so the skill's default applies: **silent video**,
newcomer audience with high-school maths, intuitive depth, 60 to 150 s, 1920x1080 at 60 fps.
This assumption is repeated in the final report (`review.md`).
