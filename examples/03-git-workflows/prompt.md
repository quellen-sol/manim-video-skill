# Prompt

> show an animation of git actions - commit, branching, merging, rebasing, conflict resolution strategies in an enterprise environment, etc

## Narration assumption (Step 0)

The skill asks "Do you want spoken narration (Kokoro text-to-speech), or a silent video?" before
planning. The user could not be reached in this run, so the skill's defaults apply:

- **silent** video (short on-screen captions carry the words),
- newcomer audience (knows what a file and a "save" are, nothing about git),
- intuitive depth, 16:9, 1920x1080 at 60 fps.
- Length: the request is broad (five topics plus "enterprise"), so per SKILL.md "Scope" it is
  grouped into 6 chapters and kept at about 3 minutes rather than the 60 to 150 s default.
