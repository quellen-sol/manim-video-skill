# Prompt

> Show the Fourier series as rotating circles (epicycles) drawing a shape.

## Step 0 answers

- Narration: **silent** (the user wants no narration).
- Audience, depth, length: not specified, so the skill defaults apply: newcomer with
  high-school maths, intuitive depth, 60 to 150 s, 16:9 at 1920x1080, 60 fps.
- Test-run constraints: build up from one rotating vector, to two adding tip to tail, to many,
  and show how adding terms sharpens the drawing.
